# I am Bhavesh Panjala

Personal portfolio and blog built with Astro. Includes blog posts, project showcase, and full-text search powered by Pagefind.

**Live:** [flamezenith.github.io](https://flamezenith.github.io)

## Setup

```bash
npm install
npm run dev        # dev server at localhost:4321
npm run build      # production build + search index
```
